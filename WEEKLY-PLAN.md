# Weekly frontend push plan

Goal: push regularly, in small real increments, so any maintainer can see clean,
reviewable work — not tutorial dumps.

## Cadence (3–4 pushes a week)

- **Mon / Wed / Fri:** one small feature or fix, on its own branch, PR to main
- **Sun:** README polish + demo link share
- Every PR: small diff, clear title, what changed, how it was tested, screenshot for UI

## react-ui-lab roadmap (1 component a week)

1. **Week 1 — Modal:** accessible, Escape to close, focus trap, overlay click to close
2. **Week 2 — Data table:** sort, filter, pagination, empty state
3. **Week 3 — Dropdown / Select:** keyboard navigation, outside-click close
4. **Week 4 — Form with validation:** inline errors, disabled submit until valid

Each component folder gets: component code, a demo page, and a short README
with props, usage, and accessibility notes.

## Achievements track

- YOLO: merge a PR without a review (own repo only)
- Pull Shark: 2 merged PRs
- Quickdraw: close a real issue within 5 minutes of opening it
- Next: Pair Extraordinaire (co-author a merged PR with a teammate),
  Starstruck (16 stars on one repo — needs sharing a genuinely useful repo)

## Rules

- No empty commits, no star-trading, no spam PRs to other projects.
- Production repos (AppScribe, ResumeIQ) only change on a branch, after a
  build check, and a merge only on an explicit go.
